# Setup

1. Install [pixi](https://pixi.sh/dev/)
2. Install the pixi environment using `pixi install` in your terminal
3. Download the dataset from [Google Drive](https://drive.google.com/drive/folders/1GsiOrOht1GiLRErvM_8PoCnJPQ1siBf7)
4. Run `model_training.py``
5. Run `model_prediction.py`
6. Observe the optimal path in `optimal_path_map.png`
